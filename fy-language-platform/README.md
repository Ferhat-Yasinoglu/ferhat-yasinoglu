# FY Language Platform — taslak ekranlar

*Bütün diller, bütün kurslar, tek platform.* Afganistan'daki dil kurslarını tek çatı altında toplayan platformun **ilk görünüm taslağı**. Siyah zemin, altın yazı. Henüz giriş sistemi ve veritabanı yok; tıklamalar iş yapmaz, veriler örnektir.

Açmak için `index.html` dosyasını tarayıcıda açın. Tüm ekranların listesi `taslak/index.html` içindedir.

| Ekran | Dosya |
|---|---|
| Açılış sayfası | `index.html` |
| Kursla İletişim formu | `iletisim.html` |
| 1 · Kurs paneli (genel bakış) | `taslak/panel.html` |
| 2 · Öğrenci kayıt formu | `taslak/ogrenci-kayit.html` |
| 3 · Öğretmenler, ders saatleri, yoklama | `taslak/ogretmenler.html` |
| 4 · Haftalık ders programı | `taslak/ders-programi.html` |
| 5 · Ödemeler, borç takibi, finans raporu | `taslak/odemeler.html` |
| 6 · Kurs sayfası (logo, adres, telefon) | `taslak/kurs-sayfasi.html` |

Ortak stil `style.css` içinde; renkler ve yazı tipleri en üstteki `:root` bloğundan değişir.

## Sıradaki adımlar

1. Logo ve renklerin son hali.
2. Gerçek giriş sistemi (her kursun kendi hesabı).
3. Veritabanı ve formların çalışır hale gelmesi.
